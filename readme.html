# ♟️ Simple 3D Chess Sandbox A minimalist, highly readable, browser-based Chess board with a cool 3D perspective effect. Built purely with HTML, CSS, and Vanilla JavaScript. ## 🌟 Features * **3D Visuals:** Uses CSS `perspective` and `transform` to give the board depth and make the pieces "pop" off the screen. * **Human-Readable Code:** Designed with beginners in mind. The logic is kept deliberately simple. * **Sandbox Mode:** Move any piece anywhere! There are no strict movement rules enforced yet, making it a perfect playground to learn how drag-and-drop/click-to-move works in JS. * **Zero Dependencies:** No images to download, no heavy libraries to install. It uses standard text-based Unicode characters for chess pieces. ## 🚀 How to Run 1. Download or clone this repository. 2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari). 3. Click a piece to select it (it will highlight yellow). 4. Click an empty square or an enemy piece to move it there. ## 🛠️ Built With * **HTML5:** For the board structure. * **CSS3:** For the 3D rendering, shading, and hover animations. * **Vanilla JavaScript:** For rendering the grid and handling click-to-move logic. ## 🔮 Future Improvements (Feel free to contribute!) If you'd like to fork this repo and make it better, here are some ideas: - [ ] Add strict movement rules for each piece (knights in L-shapes, etc.) - [ ] Add a turn system (White's turn, Black's turn). - [ ] Add a check/checkmate detection system. - [ ] Add a "Reset Board" button. --- *Created as a fun, open-source learning project!*
